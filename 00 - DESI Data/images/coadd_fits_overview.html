FITS file structure
coadd-main-dark-0.fits · 19 HDUs · 1704 targets
PRIMARY
HDU 0 · no data arrays
Pipeline configuration and instrument metadata. 157 header cards.
FIBERMAP
HDU 1 · 1704 rows × 67 columns
One row per coadded target. Contains sky coordinates, imaging photometry, morphology, targeting flags, Gaia crossmatch identifiers, and coadd summary statistics.
EXP_FIBERMAP
HDU 2 · 2356 rows × 26 columns
One row per exposure per fiber. Contains per-exposure timestamps (MJD), exposure times, tile and fiber identifiers, and fiber positioning measurements.
Spectral HDUs
HDUs 3–17 · five HDUs per camera · 1704 targets each
DESI's spectrograph splits incoming light into three wavelength ranges using dichroic mirrors. Each produces five HDUs at the same level in the file — wavelength grid, flux, inverse variance, pixel mask, and resolution matrix.

SCORES
HDU 18 · 1704 rows × 42 columns
Per-target signal-to-noise and spectral quality metrics across all three cameras.
FIBERMAP, the spectral arrays, and SCORES all share the same 1704-target row axis — each row index refers to the same fiber across all science HDUs.
